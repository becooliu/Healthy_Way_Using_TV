# 健康看电视 - 开发文档

## 一、项目概述

### 1.1 项目简介

**健康看电视**是一款运行在 Android 智能电视（长虹等品牌）上的应用，用于控制电视使用时长，保护观看者身心健康。家长可设置每次观看时长，到期自动锁定屏幕，输入密码或等待自动解锁后方可继续使用。

### 1.2 核心功能

- ✅ 可配置的观看时长（1~480 分钟）
- ✅ 可配置的提前提醒时间（1~30 分钟，默认 2 分钟）
- ✅ 到时自动锁定屏幕
- ✅ 密码解锁（4~6 位数字）
- ✅ 不输入密码等待 20 分钟自动解锁
- ✅ 开机自动恢复计时状态
- ✅ 前台服务稳定运行

## 二、项目架构

### 2.1 架构设计原则

- **高内聚**：每个模块职责单一，相关功能集中管理
- **低耦合**：模块间通过接口/广播通信，不直接依赖实现
- **单向数据流**：UI → ViewModel → Service/Data → UI

### 2.2 架构分层

```
┌─────────────────────────────────────┐
│          UI 层 (Compose)             │
│  MainScreen  SettingsScreen  LockScreen │
└──────────────┬──────────────────────┘
               │  StateFlow / 事件
┌──────────────▼──────────────────────┐
│        ViewModel 层                  │
│  MainViewModel  SettingsViewModel  LockViewModel │
└──────────────┬──────────────────────┘
               │  LocalBroadcast / Intent
┌──────────────▼──────────────────────┐

               │  SharedPreferences
┌──────────────▼──────────────────────┐
│        Data 层                       │
│  PreferencesManager  TimerConfig     │
└─────────────────────────────────────┘
```

## 三、核心流程

### 3.1 计时工作流程

```
用户点击"开始计时"
       │
       ▼
TimerService.handleStartTimer()
       │
       ▼
读取配置(duration, warningTime, password)
       │
       ▼
启动前台服务 + 倒计时协程
       │
       ├── 剩余时间 = warningThreshold
       │   └── 发送警告通知 + 广播
       │
       ├── 剩余时间 = 0
       │   └── 启动 LockScreenActivity
       │
       └── 用户停止/解锁
           └── 停止服务 + 清理状态
```

### 3.2 锁定/解锁流程

```
Timer 到期 → LockScreenActivity 启动
       │
       ├── 用户输入密码 → 验证哈希
       │   ├── 匹配 → TimerService.ACTION_UNLOCK → 解锁
       │   └── 不匹配 → 清空输入 + 提示错误
       │
       └── 等待 20 分钟
           └── 自动解锁 → TimerService.ACTION_UNLOCK
```

### 3.3 开机恢复流程

```
系统启动 → BootReceiver.onReceive()
       │
       └── 检查 SharedPreferences
           ├── isTimerRunning = true → 恢复计时
           ├── isLocked = true → 启动锁定
           └── 否则 → 不做操作
```

## 四、关键类说明

### 4.1 `PreferencesManager`（数据层）

- **设计模式**：单例模式
- **功能**：统一管理 SharedPreferences 读写
- **扩展方法**：`getConfig()` / `saveConfig()` / `clearTimerState()`
- **密码存储**：使用 SHA-256 哈希，不存明文

### 4.2 `TimerService`（服务层）

- **类型**：前台服务（Foreground Service）
- **通信方式**：通过 `LocalBroadcastManager` 发送状态广播
- **核心方法**：
  - `handleStartTimer()` —— 启动倒计时
  - `handleStopTimer()` —— 停止倒计时
  - `handleUnlock()` —— 解锁处理
  - `runTimer()` —— 倒计时主循环

### 4.3 `LockScreenActivity`（锁定界面）

- **防退出机制**：
  - 拦截 `KEYCODE_BACK`、`KEYCODE_HOME`、`KEYCODE_MENU`
  - `onUserLeaveHint()` 中重新启动自身
- **自动关闭**：监听 `BROADCAST_UNLOCKED` 和 `BROADCAST_STOPPED`

### 4.4 `LockViewModel`（锁定逻辑）

- **密码验证**：输入满 4 位自动验证
- **自动解锁**：20 分钟倒计时，每秒更新

## 六、二次开发指南

### 6.1 修改默认配置

编辑 `TimerConfig.kt` 中的默认值：

```kotlin
data class TimerConfig(
    val durationMinutes: Int = 30,   // 修改默认时长
    val warningMinutes: Int = 2,     // 修改默认提醒时间
    ...
)
```

### 6.2 修改自动解锁时间

编辑 `LockViewModel.kt` 中的 `startAutoUnlockCountdown()` 方法：

```kotlin
var remaining = 20 * 60 // 修改 20 为所需分钟数
```

### 6.3 添加新功能

1. **新增数据字段**：在 `TimerConfig` 中添加属性，在 `PreferencesManager` 中添加 getter/setter
2. **新增 UI 界面**：在 `ui/` 下创建新包，添加 Composable 和 ViewModel
3. **新增服务功能**：在 `TimerService` 中添加 Action 常量和处理方法

### 6.4 自定义锁屏样式

编辑 `LockScreen.kt` 中的 `LockScreen` 和 `NumberPad` 组件，调整颜色、字体、布局等。

### 6.5 国际化

在 `strings.xml` 中添加翻译资源，修改 `res/values-xx/strings.xml`。

## 八、注意事项

1. **权限说明**：`SYSTEM_ALERT_WINDOW` 权限在某些电视厂商的系统上可能受限，锁屏防退出功能可能无法完全生效
2. **前台服务**：Android 14+ 对前台服务类型有严格限制，当前使用 `dataSync` 类型
3. **密码安全**：密码使用 SHA-256 哈希后存储，但 SharedPreferences 本身未加密，有 root 权限的设备可读取
4. **测试建议**：在不同品牌（长虹、小米、海信等）的 Android TV 设备上测试兼容性
